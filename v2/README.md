# Dark Logo Resume Version

This directory is a separate working copy of the resume landing page. The production site at the repository root remains unchanged.

Preview from the repository root:

```bash
python3 -m http.server 4173
```

Then open `http://127.0.0.1:4173/v2/`.

The page uses local, project-relative assets and is compatible with the GitHub Pages project path at `/keanan-wilson-resume/v2/`.
