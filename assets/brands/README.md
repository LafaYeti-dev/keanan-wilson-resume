# Brand Asset Provenance

These assets are used only in the separate dark resume version under `v2/`. They identify tools, platforms, and employers named in the approved resume content.

## Tools and platforms

- Jira, Confluence, SharePoint, Microsoft Teams, OneDrive, Figma, Bitbucket, GitHub, Azure, WordPress, ClickUp, Trello, Upwork, and Google Workspace: vector marks downloaded from the corresponding Iconify `logos` or `thesvg-color` collections on 2026-09-07. Source endpoint pattern: `https://api.iconify.design/<collection>:<icon>.svg`.
- Microsoft 365: vector mark from Wikimedia Commons, `Microsoft 365 (2022).svg`, sourced from Microsoft.
- Excel: vector mark from Wikimedia Commons, `Microsoft Office Excel (2019-2025).svg`, sourced from Microsoft/Office.com.
- LearnDash: sanitized vector wordmark served by the official LearnDash website through its Cloudinary account.
- Adobe Workfront: 512-pixel product mark served by Adobe HelpX through Adobe Scene7 (`Workfrontlogo2023-1`).

All tool marks are stored locally so the resume has no runtime dependency on a third-party image host.
